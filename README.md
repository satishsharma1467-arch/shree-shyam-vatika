## GitHub Pages

1. Create a GitHub repository, for example `shree-shyam-vatika`.
2. Upload all files from this folder.
3. In GitHub: Settings → Pages.
4. Choose GitHub Actions or Deploy from a branch.
5. Set the custom domain to `shreeshyamvatika.com`.
6. Configure the domain DNS records as GitHub instructs.
7. Enable HTTPS after DNS has propagated.

Do NOT change your current Hostinger DNS until the GitHub repository has been
published and the GitHub Pages custom-domain setup is ready.
